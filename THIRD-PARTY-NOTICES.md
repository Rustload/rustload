# Third-party notices

Rustload itself is released under the [MIT license](LICENSE). It ships with the following
third-party work, under their own licenses. The full license texts of everything compiled into the
binary, the web interface and the browser extension are in
[THIRD-PARTY-LICENSES.md](THIRD-PARTY-LICENSES.md); the Docker image carries both files in
`/usr/share/doc/rustload/` and the release archives next to the binary. The desktop app also
compiles in [Tauri](https://tauri.app) and its dependencies (permissive licenses, plus the Mozilla
Public License 2.0 for five crates used unmodified: cssparser, cssparser-macros, selectors,
dtoa-short and option-ext): they are listed in
[desktop/THIRD-PARTY-LICENSES.md](desktop/THIRD-PARTY-LICENSES.md), installed with the app. On
Windows it uses the system's Microsoft Edge WebView2 runtime, which its installer downloads from
Microsoft when it is missing.

## Installed on request on Windows

Rustload ships neither of these: *Install* in the settings downloads them from their official
releases, verifies their checksums and puts them in `<config>/bin/`, where Rustload runs them as
separate processes.

## Source code

The programs above under the GNU GPL or LGPL come with their source code:

- **Alpine Linux packages** (FFmpeg, BusyBox, the codec libraries...): the image is based on Alpine
  Linux 3.24. The build recipes are in the
  [aports repository, branch `3.24-stable`](https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.24-stable)
  (for example [`community/ffmpeg/APKBUILD`](https://gitlab.alpinelinux.org/alpine/aports/-/blob/3.24-stable/community/ffmpeg/APKBUILD)),
  and the corresponding source archives on the
  [Alpine distfiles mirror](https://distfiles.alpinelinux.org/distfiles/v3.24/).
- **7-Zip 26.02**: [`7z2602-src.tar.xz`](https://7-zip.org/a/7z2602-src.tar.xz) from
  <https://www.7-zip.org/download.html>; **7-Zip 26.04**:
  [`7z2604-src.tar.xz`](https://github.com/ip7z/7zip/releases/download/26.04/7z2604-src.tar.xz).
- **FFmpeg builds installed on Windows**: the sources and build scripts are linked from
  <https://github.com/yt-dlp/FFmpeg-Builds>.
- **yt-dlp**: <https://github.com/yt-dlp/yt-dlp/tree/2026.08.19>.

If a link no longer works, open an issue and we will provide the source code.
